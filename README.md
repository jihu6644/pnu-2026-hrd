# 2026 부산대학교 교직원 직무연수 안내 웹사이트

부산대학교 교직원(전 직원, 실무자, 관리자, 신규자)을 위한 2026년도 직무연수 프로그램 종합 안내 및 수강신청 지원 포털입니다.

## 🌟 주요 특징

1. **실시간 구글 시트 연동 (Live Data Sync)**
   - 구글 스프레드시트(GViz CSV API)에서 연수 데이터를 실시간 스트리밍으로 파싱합니다.
   - 담당자가 구글 시트에서 내용을 수정하면 별도 배포나 코드 수정 없이 웹페이지 새로고침 시 즉각 반영됩니다.
   - 쉼표, 특수기호, 줄바꿈 처리를 위해 `PapaParse` 엔진을 적용했습니다.

2. **다차원 복합 검색 및 필터링**
   - **통합 검색**: 과정명, 분야, 담당부서, 한줄소개 실시간 키워드 검색 (Debounce 적용)
   - **직무 분야 탭**: 법정의무교육, 직무공통, 예산·회계, 인사·노무, 정보화·AI·데이터, 대학행정 특화, 소통·CS, 리더십, 안전·보건, 어학 등 10대 카테고리 원클릭 필터링
   - **상세 조건 필터**: 이수구분(필수/권장/선택), 교육방식(온라인/집합/혼합), 대상(전직원/실무자/관리자/신규자), 주관부서

3. **직관적인 2페이지 사용자 경험**
   - **메인 페이지 (`index.html`)**: 연간 직무연수 현황 통계 대시보드, 법정의무교육 이수 배너, 반응형 3열 카드 그리드
   - **상세 페이지 (`detail.html?code=...`)**: 6대 핵심 메타 벤토 그리드, 과정 상세 소개, 체크리스트형 학습 목표, 단계별 커리큘럼, 수강신청 원클릭 아웃링크, 담당부서 전화 문의, 링크 복사

4. **접근성 및 모바일 반응형 지원**
   - 데스크톱, 태블릿, 모바일 스마트폰 전 기기 완벽 지원
   - 부산대학교 대표 브랜드 컬러(Navy Blue `#003876`) 기반의 신뢰감 있는 디자인 시스템

```

├── css/
│   ├── style.css                # 글로벌 디자인 토큰, GNB 헤더, 푸터, 배지, 토스트 공통
│   ├── main.css                 # 메인 전용 스타일 (히어로, 통계 바, 필터, 카드 그리드)
│   └── detail.css               # 상세 전용 스타일 (벤토 박스, 목차, 액션바)

│   └── favicon.svg              # 사이트 파비콘
├── PROJECT_PLAN.md              # 작업 기획서 원본
```
